Files are named by a path from the root: docs/paths.txt, disk:notes/today.txt
There is no current directory and no "." or "..".

  ls              the root of the in-memory file system
  ls docs         a directory (shown with a trailing / in listings)
  ls disk:        the root of the disk file system
  mkdir disk:notes
  write disk:notes/today.txt hello
  cat disk:notes/today.txt
  rm disk:notes/today.txt
  rm disk:notes   a directory can be removed once it is empty
